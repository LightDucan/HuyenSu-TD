# Hero Rules — Read First

Hero là Tower mang hình tướng. Chỉ số core: `hp`, `atk`, `range`, `attackSpeed`, `crit`, `critDamage`; không có DEF.

Normal attack luôn single-target. AoE, Slow, Stun, Root và MultiHit chỉ xuất hiện qua framework Skill Effects dùng chung. Không tạo code combat riêng cho từng Hero.

Tiến hóa: Normal Lv1–100 → Rebirth Lv1–100 → Reincarnation Lv1–100 → Legendary. Legendary mở Passive đặc biệt.

Chi tiết schema: [data-schema.md](data-schema.md). Luật gameplay đầy đủ: [game-rules.md](game-rules.md).
