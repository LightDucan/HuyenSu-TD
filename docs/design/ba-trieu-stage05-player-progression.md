# Bà Triệu Stage 05 — Player Progression

Stage 05 is available only after the player has completed the preceding Bà Triệu stages through `bt-04-lap-luy-bo-dien`. Before that completion it remains locked; no cross-chapter shortcut is added.

The pre-battle card appears for an incomplete Stage 05 and leads into the shared battle-entry flow. A completed replay enters directly without forcing the introduction. Victory records the normal Stage 05 reward and completion, and a later replay can select the stage again while Stage 06 remains the current prototype destination.

The first clear is a local tactical success: the immediate assault is repelled and Bồ Điền remains held for now, while the wider suppression campaign continues. Defeat is a tactical withdrawal and retry, not a depiction of Bà Triệu's death or the campaign's final outcome.
